## Why the numbers differ (all intentional)

- **Level**: Pulse compensates the level of every saturation stage (tape, grit distortion, punch saturate), so turning drive up changes the *character*, not mainly the loudness. The original got louder with drive, which makes A/B judgements misleading.
- **True peak**: the original's Finish could output above 0 dBTP (it hard-clipped at the base rate, then inter-sample peaks overshot). Pulse's Finish ends in a true-peak limiter at -0.5 dBTP.
- **Tape**: Pulse adds the head bump and speed-dependent roll-off that the original's parameters promised; wow/flutter are random-but-repeatable, so the waveforms never null exactly.
- **Grit**: the original's noise types, Tone and Flux did not work (see DSP_SPEC.md issues); Pulse's noise is calibrated to the same level for every type, and distortion/digital are oversampled (less aliasing, so less top-end fizz).
- **Shape**: Pulse's detection is level-independent, so the same Attack setting gives the same effect on quiet and loud material; the original depended on input level.
- **Boom**: the original fired on absolute level; Pulse fires on kicks relative to the running low end (Sensitivity control) and resets the sub phase on every hit, so each boom is identical.
